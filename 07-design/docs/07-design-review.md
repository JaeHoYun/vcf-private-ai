# 07 — 설계 리뷰 체크리스트와 검증 관문

[← 목차로](../README.md)

설계를 끝내기 전에, **모든 결정이 내려졌고 근거가 기록됐는지**를 점검합니다. 이 문서는 결정별 체크리스트와 단계별 검증 관문, 그리고 추적성 점검을 제공합니다.

> 본 문서의 항목은 작성 시점(2026-06, 9.1.1과 PAIS 3.0 GA 반영 2026-09) VCF 9.1.1 / PAIF 9.1.1 / PAIS 3.0 기준이며, 적용 전 공식 문서로 재확인하시기 바랍니다.

## 7.2 단계별 검증 관문

각 관문은 다음 단계로 넘어가기 전에 충족해야 할 조건입니다.

- **Gate 0 — 요구사항** : [결정 요인 시트](../worksheet/01-driver-sheet.md)가 수치와 등급으로 채워졌는가. 서비스 수준 목표(SLO)가 측정 가능한가.
- **Gate 1 — 토폴로지와 컴퓨트** : D1–D4 결정과 기록 완료. GPU 하드웨어가 선택한 공유 방식(MIG 등)을 지원하는가. 최소 호스트 요건 충족.
- **Gate 2 — 네트워크와 스토리지** : D5–D8 결정과 기록 완료. VPC 셀프서비스가 목표면 오버레이 전제 충족. 프린시플 스토리지 선택이 VCF 9.1 지원 범위인가(iSCSI 프린시플 불가).
- **Gate 3 — 보안과 테넌시** : D10–D12, D14 결정과 기록 완료. 에어갭 등급이 규제 요건과 일치. Identity 페더레이션과 격리 모델이 감사 요건 충족. 보호 문서 복호화 존의 경계와 파생 사본 재보호가 [05 5.4절](05-tenancy-security.md)과 [⑤ 05 5.9절](../../05-security/docs/05-data-governance.md)에 부합.
- **Gate 4 — 가용성과 운영 준비** : D9 결정과 기록 완료. 패스스루 GPU의 HA 제약을 앱 레벨 replica로 보완. 백업, 복구, 수명주기 관리(LCM) 운영 계획(① Day-2) 연결.
- **Gate 5 — 서비스 보호** : D13, D15, D16 결정과 기록 완료. 게이트웨이 계층별 책임 매트릭스([③ 05 5.7절](../../03-serving-api/docs/05-auth-and-gateway.md))가 문서로 고정되어 이중 정책이 없는가. 가드레일 삽입 지점이 출력 가드를 생성 모델과 분리하고 검색 청크와 도구 결과 살균을 앱 안에 두는가([⑤ 06 6.5절](../../05-security/docs/06-app-guardrails.md)). 에이전트 자율성 상한이 위험 등급 매트릭스([⑤ 08 8.3절](../../05-security/docs/08-agent-governance.md)) 안에 있고 승격과 강등 조건이 적혀 있는가. 대외 노출 서비스나 규제 출시 심사 대상이면 앱 가이드 12의 서비스 보안 점검과 연결.

## 7.3 추적성 점검

설계가 끝나면 다음 체인이 끊기지 않는지 확인합니다.

```
결정 요인(01)  →  설계 결정(06 카탈로그)  →  설계 결정 기록(06.3)  →  블루프린트 조정(02)
```

- 모든 결정 기록이 하나 이상의 결정 요인으로 거슬러 올라가는가(근거 없는 결정 없음).
- 블루프린트에서 바꾼 결정이 모두 설계 결정 기록에 남았는가.
- 형제 가이드로 위임한 항목(보안 상세와 사이징 수치)이 해당 가이드에서 검증됐는가.

> 결정, 근거, 검증의 추적 체인이 이어져야 나중에 "왜 이렇게 설계했나"에 답할 수 있습니다.
